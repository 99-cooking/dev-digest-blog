# Dev Digest — May 5, 2026

## 🔥 HOT RELEASES

**Ollama × Claude Desktop Integration**
Ollama now supports Claude Desktop via built-in third-party inference. Run `ollama launch claude-desktop` to use any Ollama Cloud model across Claude Cowork and Claude Code. Huge for local-first AI coding.
🔗 X: https://x.com/ollama/status/2051445924464140575

**Gemini API Webhooks**
Google shipped webhooks in the Gemini API — no more polling for long-running tasks. Big improvement for batch jobs, agents, and generative media pipelines. Cloudflare already has a Workers example.
🔗 X: https://x.com/OfficialLoganK/status/2051434527931953490
💻 Cookbook: https://github.com/google-gemini/cookbook/blob/main/quickstarts/Webhooks.ipynb

**AI Studio Vibe Coding — Edit Mode**
Google's AI Studio now has visual edit mode for vibe coding: select components to edit them, annotate UI with a pen tool, swap image assets with Nano Banana. Moving closer to direct manipulation + AI generation.
🔗 X: https://x.com/OfficialLoganK/status/2051698665652412919

**Unsloth: Open LLMs in Claude Code, Codex & OpenClaw**
New guide on running Gemma 4 and Qwen3.6 GGUFs for local agentic coding on 24GB RAM. Self-healing tool calls, code execution — proper local alternatives to cloud models.
🔗 X: https://x.com/UnslothAI/status/2051669222011683045
📖 Docs: https://unsloth.ai/docs/basics/api

## 🔮 EMERGING TRENDS

**Local-first AI coding is maturing** — Between Ollama's Claude Desktop integration and Unsloth's guide for running Gemma/Qwen locally, the "run it yourself" stack is getting genuinely usable. 24GB RAM is the new baseline.

**Visual AI coding** — Google's AI Studio edit mode (pen annotations, component selection) signals the next phase: direct manipulation meets code generation. Cursor and friends will follow.

**Agent infrastructure diverging** — MCP, skills, hooks, subagents — the community is starting to properly differentiate these patterns. Expect cleaner architectures as the taxonomy settles.

**Zero-VM Linux on Mac** — Cocoa Way running Linux apps natively on macOS without a VM is a sleeper hit. If it works well, massive for dev environments.
