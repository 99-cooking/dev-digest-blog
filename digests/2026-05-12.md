## 💡 TECHNIQUES & IDEAS

**npm Supply Chain Defense: Minimum Release Age**
Hot tip trending big (1,318 likes): configure your package manager to enforce a cooling period on new package installs. Blocks supply-chain attacks during the critical window after malicious publish.
- Bun: `minimumReleaseAge = 604800` (seconds)
- pnpm: `minimumReleaseAge=10080` (minutes)
- npm v11.10+: `min-release-age=7` (days)
🔗 X: https://x.com/RhysSullivan/status/2053954791668367563

**npm_ex — Elixir npm Package Manager (No Node.js)**
In response to npm attacks: pure Elixir npm package manager with blocked lifecycle hooks, transitive git/url deps blocked by default, OSV/OpenSSF audit.
🔗 X: https://x.com/dan_note/status/2054214925854052537
