**Anthropic — Claude Code Review**
Multi-agent code review system that dispatches parallel AI agents to review PRs, each examining from a different angle. A final agent aggregates findings, removes duplicates, and ranks by severity. Internal tests show it catches bugs 84% of the time on 1000+ line changes. $15-$25 per PR review.

**Anthropic — Claude Code Voice Mode**
Talk to your coding agent. Voice mode is rolling out gradually (~5% of users initially). Speak your instructions instead of typing — useful for pair-programming style workflows and quick architecture discussions.
🔗 TechCrunch: https://techcrunch.com/2026/03/03/claude-code-rolls-out-a-voice-mode-capability/

## 💡 TECHNIQUES & IDEAS

**AI "Convenience Loops" Reshaping Language Choice**
GitHub Octoverse data reveals a feedback loop: AI coding tools work best with statically typed languages → developers migrate to TypeScript → AI gets better at TypeScript → more migration. TypeScript surged 66% to become GitHub's #1 language. Types = guardrails for LLMs.
🔗 InfoQ: https://www.infoq.com/news/2026/03/ai-reshapes-language-choice/

**Google Android Bench**
Google released a public leaderboard ranking AI models for Android app development. Gemini 3.1 Pro Preview leads at 72.4% success rate, followed by Claude and GPT models. Useful if you're picking models for mobile dev.
🔗 9to5Google: https://9to5google.com/2026/03/06/google-says-these-ai-models-are-best-at-coding-android-apps/

**Amazon's AI-Linked Outage**
Amazon's site crashed on March 5 for ~6 hours — checkout, login, pricing all broken. 21K+ outage reports. Root cause: faulty code deployment where engineers used AI coding tools. Not the first time. Cautionary tale for shipping AI-generated code without proper review (makes Claude Code Review's timing perfect).
🔗 X: https://x.com/karankendre/status/2031434170598355394
