## 🔮 EMERGING TRENDS

**🚨 Glassworm Supply Chain Attack — 151+ GitHub Repos Compromised**
Critical security alert: Aikido Security discovered "Glassworm" hiding malicious payloads in invisible Unicode characters across 151+ GitHub repos, npm packages, and VS Code extensions (March 3-9). Uses blockchain for C2 to steal tokens, credentials, and secrets. Targets include Wasmer, Reworm, and anomalyco (OpenCode/SST). Suspected LLM-generated at scale. **Audit your dependencies.**
🔗 https://arstechnica.com/security/2026/03/supply-chain-attack-using-invisible-code-hits-github-and-other-repositories/
