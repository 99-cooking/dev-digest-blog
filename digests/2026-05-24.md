**Bun's Zig→Rust Port: "Languages Are Now Mutable"**
Jarred Sumner clarifies the Bun rewrite — ported to Rust for compiler-assisted tooling to fix bugs, not because Zig is bad. His take: "Programming languages are now a mutable technical decision you can change in like a week." Legacy codebases become valuable sources for "distilling" code into new forms.

**Agent Architecture Pattern: The Boring Trick**
Solid breakdown: agent = plan → act → observe → repeat. Split tasks until each step has clear I/O. Use cheap models for easy steps, big models only where reasoning matters. Add guardrails (code checks, LLM judge, human review). Result: $0.08/run production systems.
