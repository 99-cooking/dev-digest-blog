## 🔐 SECURITY ALERT

**node-ipc Compromised Again**
Three malicious versions (9.1.6, 9.2.3, 12.0.1) published via expired-domain account takeover. Credential stealer harvests AWS/GCP/Azure keys, SSH keys, npm tokens, .env files — exfiltrates via DNS TXT queries. CommonJS consumers affected; ESM-only safe. If you loaded it, rotate ALL credentials immediately.
🔗 X: https://x.com/feross/status/2055006045077230048
