## 💡 TECHNIQUES & IDEAS

**SkillOpt — Train the Playbook, Not the Model** (Microsoft Research)
Instead of retraining AI models, optimize the external skill documents they read. An optimizer model makes validation-gated edits to skill files (add rules, remove bad advice, rewrite instructions). Results: spreadsheet solving 41.8% → 80.7%, works across GPT + Qwen models, learned skills transfer between models and harnesses. Zero extra inference cost.
🔗 X: https://x.com/omarsar0/status/2058936160291004483 (1000+ likes)
📄 Paper: https://arxiv.org/abs/2605.23904
🌐 Site: https://microsoft.github.io/SkillOpt/

**Claude "Dreaming" Agents** (Code with Claude London)
Anthropic demoed agents that rewrite their own memory overnight — merging useful info, deleting stale data, surfacing new patterns. 4-layer memory system. The first 3 layers you can build yourself tonight: a file the agent reads/writes each session, a filter for what survives, and a weekly consolidation job.
🔗 X: https://x.com/dunik_7/status/2059186612739674407

**Claude Code Routines — Proactive Agents**
Claude Code now supports "Routines" — scheduled or event-triggered agent runs (e.g., on GitHub issue creation, PR labeling). No infrastructure to manage, no cron jobs. The agent goes from reactive to proactive.
🔗 X: https://x.com/neil_xbt/status/2059125372864627027

## 🔮 EMERGING TRENDS

**The Terminal Agent War is Here**
Four major players now have terminal-native AI coding agents: Claude Code, OpenAI Codex, Google Antigravity CLI, and xAI Grok Build. Plus Hermes can orchestrate all of them. The IDE is becoming optional — the terminal is the new battleground.

**Agent Orchestration is the Next Layer**
Hermes Agent orchestrating OpenHands, Claude Code, Codex, and itself. BullMQ MCP for queue management from your IDE. AdminForth making admin panels agent-accessible. The trend: every tool is getting an agent interface.

**Skill Optimization > Model Training**
Microsoft's SkillOpt paper shows that optimizing what you tell the model (skill docs, prompts) can be more effective than changing the model itself. Expect "trainable prompt" frameworks to proliferate.

**Self-Evolving Agent Memory**
Anthropic's "dreaming" agents, self-rewriting skill docs, overnight consolidation — agents that improve themselves between sessions are becoming a real pattern, not just research.
