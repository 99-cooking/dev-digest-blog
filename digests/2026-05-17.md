**MCP Architecture Patterns**
5 server patterns emerging in production: Tool Server (agent actions), Resource Server (read-only context), Prompt Server (managed prompt infrastructure), Gateway Server (single endpoint routing), and Proxy/Bridge Server (wrapping legacy APIs). Most production deployments use all five.
🔗 X: https://x.com/leopardracer/status/2055917148061700480
