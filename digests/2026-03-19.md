JetBrains launches Air, a dedicated agentic dev environment built on 26 years of IDE experience. ## 💡 TECHNIQUES & IDEAS

**The Developer-as-Manager Shift**
Business Insider reports Google and others are using AI to handle bulk coding, shifting developers toward decision-making and oversight roles. The NYT's long-form "Coding After Coders" piece describes devs who "rarely write code" anymore — spending days talking to AI agents in plain English and reviewing their plans.
🔗 https://www.businessinsider.com/ai-coding-changing-software-developer-role-2026-3
🔗 https://www.nytimes.com/2026/03/12/magazine/ai-coding-programming-jobs-claude-chatgpt.html

**OpenAI Codex Smart Approvals**
Guardian-based approval system for autonomous coding agents. Instead of blanket permissions or constant interruption, the guardian evaluates each action against policies. This is the pattern for safe agent autonomy.

**Multi-Agent Orchestration as the Default**
JetBrains Air, Codex's spawn_agent/wait_agent pattern, and the agency-agents repo all point the same direction: the future isn't one AI coding assistant, it's managing a team of them with different specializations.

## 🔮 EMERGING TRENDS

**GlassWorm: Supply Chain Attack via Invisible Unicode**
400+ compromised repos on GitHub, npm, and VSCode/OpenVSX. Uses invisible Unicode characters to hide malicious code that evades standard code review. Queries Solana blockchain every 5 seconds for C2 updates. Steals npm/GitHub/Git credentials and crypto assets. Check your dependencies.
🔗 https://www.bleepingcomputer.com/news/security/glassworm-malware-hits-400-plus-code-repos-on-github-npm-vscode-openvsx/

**Agent Client Protocol (ACP) Gaining Traction**
JetBrains and Zed are pushing ACP as the standard for AI agent interoperability. The ACP Agent Registry launched in January, and Air's adoption signals it's becoming the plumbing layer for multi-agent IDEs.

**Skills Ecosystem Exploding**
5 of the top 10 new GitHub repos this week are agent Skills (SwiftUI, Medical, etc.). The pattern of packaging domain expertise as reusable agent skills is becoming a category unto itself. OpenClaw's skills ecosystem is part of this wave — the NYT and CNBC both covered OpenClaw's rapid GitHub adoption this week.

**Vibe Coding Goes Full-Stack**
Google's AI Studio update shows vibe coding isn't just prototyping anymore — it's multiplayer games with real-time networking, persistent sessions, and production deployments. The gap between "prompt" and "product" keeps shrinking.
