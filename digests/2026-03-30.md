## 💡 TECHNIQUES & IDEAS

**Claude Code /loop Workflows**
Boris Cherny (Anthropic) runs loops like `/loop 5m /babysit` for auto-rebasing PRs, `/loop 30m /slack-feedback` for auto-PR from Slack feedback, `/loop 1h /pr-pruner` for closing stale PRs. Turn any workflow into a skill + loop.
🔗 X: https://x.com/bcherny/status/2038454341884154269

**Session Teleportation**
`claude --teleport` moves cloud sessions to local machines. `/remote-control` lets you control local sessions from phone/web. Start on mobile, continue on desktop seamlessly.

**Git Worktrees for Parallel Claude Sessions**
Run dozens of Claude instances simultaneously using `claude -w` with git worktrees. Combined with `/batch`, you can distribute work across hundreds of parallel agents.

**tldraw Migration Skills**
tldraw plans to ship SDK migration skills — invoke a command to auto-upgrade and fix breaking changes between versions. Pattern worth watching for other libraries.
🔗 X: https://x.com/steveruizok/status/2038372641531191742
💻 GitHub: https://github.com/tldraw/tldraw/pull/8373

## 🔮 EMERGING TRENDS

**Agent Skills Ecosystem Explosion**
March's GitHub trending is dominated by Claude Code skills/agents frameworks. Superpowers (124k stars), everything-claude-code (58k), deer-flow (ByteDance's SuperAgent), OpenViking (Volcengine's context DB for agents). The "agentic skills" pattern is becoming the dominant way to organize AI-assisted development.

**Computer Use in Dev Tools**
Claude Code adding native computer use signals a shift — AI coding tools are becoming full desktop automation platforms. Write code → launch app → visually test → fix bugs, all in one loop.

**DOM-Free Web Rendering**
Pretext's approach of bypassing DOM entirely for layout computation is gaining traction. Engineers from Vercel, Figma, Remix, and shadcn are all paying attention. Could reshape how we build text-heavy UIs, especially for AI streaming interfaces.

**Open Source AI Infrastructure**
Decentralized AI clusters (Parallax), AI-native SSH (Termex), agent security (AgentArmor) — the infrastructure layer for running AI agents is rapidly maturing as open source.
