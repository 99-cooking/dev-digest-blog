# Dev Digest — March 23, 2026

## 🔥 HOT RELEASES

**TypeScript 6.0**
The big one. Ships with Temporal API support, `Map#getOrInsert`, `RegExp.escape`, new `#/` prefix for package imports, and new defaults: `target: ES2025` + `--strict` by default. Deprecates `baseUrl`, `outFile`, and several legacy options. This is a major cleanup release.
🔗 X: https://x.com/typescript/status/2036124240144216334
🔗 X (breakdown): https://x.com/robpalmer2/status/2036140215668982086
📖 Blog: https://devblogs.microsoft.com/typescript/announcing-typescript-6-0/
