## 💡 TECHNIQUES & IDEAS

**The PRD → Issues → Agent Loop Pattern**
Matt Pocock's workflow is crystallizing into a pattern: write a PRD first, decompose into issues, then let AI agents execute each issue in a loop. The key insight from replies: "Most AI coding setups break at the spec layer, not the implementation." Forcing structured specs before code = dramatically better agent output.

**Subagent Architecture for Code**
Emerging from the Pocock thread: using Claude Code subagents with narrow context for each task while a main session maintains oversight of the full PRD. Tight context = better execution. Multiple people reporting success with this pattern.

**System Prompt Engineering from the Leaked Repo**
The mega-leak of AI tool prompts reveals: every major tool uses structured persona definitions, explicit tool boundaries, and carefully layered instruction hierarchies. Common patterns: role definition → constraints → tool access → output format. Worth studying for anyone building AI features.

## 🔮 EMERGING TRENDS

**Rust TUIs Are Eating the World**
@orhundev alone is surfacing a new Rust TUI tool every few days — vortix, tsql, oracle, gitlogue. The Ratatui ecosystem is maturing fast, and "TUI for X" is becoming the default pattern for developer tools. Even TypeScript is getting in (Rezi) with native C rendering.

**The Great Tunneling Wars**
OutRay, pgrok, and others are all gunning for ngrok's lunch. Self-hosted, open-source, simpler. The fact that OutRay got into Vercel's OSS program signals this is becoming infrastructure.

**AI Coding Workflows Are Getting Structured**
The vibes-only era of AI coding is ending. PRDs, issue decomposition, feedback loops, CI integration, subagent orchestration — the tooling is maturing from "let AI write code" to "manage AI as a junior dev team."

**Go → Rust Rewrites Continue**
Verifpal (7 years of Go → Rust), TypeScript compiler (→ Go), oxlint (Rust) powered by TypeScript-Go. The rewrite cycle is alive and well, but now it's strategic rather than just "rewrite it in Rust" memes.
