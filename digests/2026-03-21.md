**Ghostling — Minimal Terminal in 600 Lines of C**
Mitchell Hashimoto (Ghostty creator) shipped a standalone minimal terminal using libghostty. Full 24-bit color, kitty keyboard protocol, mouse tracking, Unicode graphemes, scrollback — all in ~600 LoC. Proves the libghostty C API is ready for embedding.
🔗 X: https://x.com/mitchellh/status/2035114092151902357
💻 GitHub: https://github.com/ghostty-org/ghostling

**Tokio dial9 — Flight Recorder for Async Rust**
Tokio shipped dial9, a runtime flight recorder that captures polls, parks, wakes, app spans, and even Linux kernel scheduling events. Finally see *why* prod latency spikes when aggregate metrics look fine. ~5% overhead.
🔗 X: https://x.com/brk0v/status/2035310209166430362
🔗 Blog: https://tokio.rs/blog/2026-03-18-dial9
