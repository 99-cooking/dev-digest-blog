# Dev Digest — April 20, 2026

## 🔥 HOT RELEASES

**Obscura — Rust Headless Browser for AI Agents**
A headless browser engine written in Rust, designed to replace headless Chrome for AI agents and web scraping. Uses V8 for JS, supports CDP protocol (Puppeteer/Playwright compatible). 30MB memory, 85ms startup, stealth mode with fingerprint randomization. A serious Chrome alternative for agent infra.
🔗 X: https://x.com/QingQ77/status/2046041157587869916
💻 GitHub: https://github.com/h4ckf0r0day/obscura

**sqz — Compress CLI Output Before It Hits Your LLM**
Rust CLI tool that auto-compresses command output before sending to LLMs. Deduplicates repeated file reads (13 tokens after first read), differentially processes git output, code (keeps only structure/signatures), JSON (strips nulls). Works with Claude Code, Cursor, Cline. VS Code + JetBrains plugins available. All local.
🔗 X: https://x.com/QingQ77/status/2046010958632362323
💻 GitHub: https://github.com/ojuschugh1/sqz

**Claude Code /cost-estimate Skill v2**
Ships evidence-based ROI analysis for Claude Code projects. Cross-checks against METR benchmarks (2.1–11.6× multiplier range), detects parallel Claude windows from session logs, validates estimates with 4 methodologies. The reality check nobody's doing on those "I saved $1M" claims.
🔗 X: https://x.com/jbarbier/status/2046040913890447667
💻 GitHub: https://github.com/jbarbier/claude-code-cost-estimate

**HyperFrames + Claude Code Video Pipeline**
Full-stack video production from a single prompt — structure, scenes, captions, voiceover, transcription. Now includes a website-to-hyperframes skill for generating video from any HTML/CSS/JS site. The creator-economy equivalent of "just ship it."
🔗 X: https://x.com/liu8in/status/2046025980645609629

**Live API Inspector — Chrome Extension**
Chrome extension that shows every API request, header, payload, and response in a clean side panel. No more digging through DevTools Network tab. Free on Chrome Web Store.
🔗 X: https://x.com/stanlee0nX/status/2046143709104804196
