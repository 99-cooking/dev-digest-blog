## 🔮 EMERGING TRENDS

**MCP Reality Check**
Perplexity's CTO told their own dev conference they're moving away from MCP internally — even while their docs have one-click MCP install. The spec hasn't been updated since Nov 2025, security model is nonexistent, and stdio transport breaks in production. APIs and CLIs won this round. Meanwhile, Claude Code is adding "tool search" for progressive MCP discovery.
🔗 X: https://x.com/aakashgupta/status/2031950037031510161
