**Agentic Coding Price War**
Grok Build at 12x cheaper than Opus, Copilot CLI shipping 27 features per release, Cursor adding automations — the IDE-as-agent-platform race is accelerating. Price is dropping fast while capabilities expand.

**MCP Everywhere**
Chrome DevTools MCP, Dub MCP, JADX-AI MCP, Hyperbrowser MCP — the Model Context Protocol is becoming the universal glue between AI agents and tools. Every product is shipping an MCP server now.

**AI Agents Go Multi-Repo**
Cursor's multi-repo automations and Copilot CLI's remote policies signal a shift from single-file coding assistants to agents that reason across entire organizations' codebases.

Silicon Studio (Apple Silicon), TransformerLab (multi-cloud GPU) — the tools for local/personal model fine-tuning are becoming drag-and-drop. The barrier to custom models keeps dropping.
